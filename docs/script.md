- 时长：60 秒
- 画幅：1920×1080（逻辑画布 320×180，×6 最近邻放大）
- 声音：无配音；芯片音乐 + 音效；全片屏字

## 叙事原则

- 每条屏字只对应一个可见动作，不写抽象概念。
- 用「取指 → 译码 → 执行 → 写回」四步做章节骨架，观众不需要懂 CPU 也能跟上。
- 数字只用 0x2A、3、5、8，避免认知负担。
- 结尾把「数十亿次开关」与开场 0.3 秒扣回，形成循环。
- 不解释晶体管物理、不展开流水线、不谈 GPU；留到下集。

## 旁白（不用于成片，供后续改编）

> 你按下发送键，0.3 秒后，回答出现了。
> 但在这一瞬间，芯片里已经跑完了数十亿次开关。
> 第一步，取指令：火花从内存 0x2A 号格子里取出一张 LOAD 指令卡。
> 第二步，译码：指令被拆成「做什么」和「对谁做」。
> 第三步，执行：两个数进入 ALU，加法器给出结果。
> 第四步，写回：结果回到内存，屏幕上的回答亮了起来。
> 每一次回答，都是几十亿次这样的奔跑。
