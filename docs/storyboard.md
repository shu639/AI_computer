# 分镜表（60 秒 / 30fps / 320×180）

## 全局视觉规则

- 逻辑画布 320×180；最终 ×6 到 1920×1080。
- Sweetie 16 色板；全片只允许这 16 色 + 透明。
- 字体：Fusion Pixel 12px Monospaced SC；只使用 12/24/36/48px。
- 精灵动画 12fps（每 2.5 个 30fps 帧换一次）；镜头按整像素移动。
- 字幕带：底部 28px，12px 字，单行最多 30 字；类型机效果 10–14 字/秒。
- 章节标签：左上角 12px；时间码：右上角 12px。
- 转场：像素擦除 / 下潜 / 闪白，不用淡入淡出模糊。

## 关键帧清单

1. 0.0s：开场聊天框，光标闪烁。
2. 1.6s：发送键按下，按钮下沉 1px。
3. 3.2s：回答气泡出现，像素逐字点亮。
4. 6.0s：下潜中段，屏幕边框变成像素隧道。
5. 12.0s：内存长廊全景，宝箱编号可见。
6. 17.0s：0x2A 宝箱打开，指令卡升起。
7. 24.0s：指令卡裂成两半。
8. 35.0s：ALU 竞技场，三个逻辑门发光。
9. 39.0s：结果 8 弹出。
10. 48.0s：回答在聊天框里逐字出现。
11. 55.0s：芯片城市拉远，火花如雨。

## 角色与道具

- BIT：12×12 火花小机器人，黄色头、银色身体、深蓝按钮；两帧待机、两帧奔跑。
- CU：16×16 控制单元向导，戴尖帽，手持指针。
- 宝箱：12×10，深蓝箱体、黄色锁扣；打开时箱盖上升 2px。
- 指令卡：24×14，银色边框，深蓝底，黄色字。
- 逻辑门：AND / OR / XOR 三个 16×12 小怪物，分别在命中时闪白。
- 结果数字：24px 黄色像素字，弹出时上浮 8px 再回弹。

## 循环设计

- 最后一帧（59.5s）回到开场聊天框构图。
- 屏字最后一句「每一次回答，都是几十亿次这样的奔跑」与第一句「你按下发送键」形成因果闭环。
- 下集预告停留 2.4 秒，给观众一个继续看的理由。
