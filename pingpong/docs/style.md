# 视觉方向：RISO 运动杂志

这一版刻意不沿用上一支 AI 芯片短片的「320×180 像素风」。制作方法仍然是**代码逐帧绘制 → Playwright 截帧 → FFmpeg 编码**，但视觉系统换成孔版印刷（risograph）质感的运动杂志：

## 画布

- 逻辑画布 960×540，Canvas 以 2× 渲染，输出 1920×1080。
- 不做像素化放大、不做 16 色量化；允许文字抗锯齿。
- 版面按杂志跨页设计：顶部报头，中部大图/图表，底部字幕条。

## 色板（5 色 + 纸色）

| 名称 | 色值 | 用途 |
|---|---|---|
| 纸色 paper | `#f3e7d3` | 背景、留白 |
| 墨色 ink | `#1b2a33` | 主文字、线稿、暗部 |
| 朱红 vermilion | `#d9482b` | 上旋、力量、重点标记 |
| 球台绿 court | `#1e6b57` | 球台、侧旋、稳定信息 |
| 蓝 ink-blue | `#2d6e8e` | 下旋、空气、技术注释 |
| 芥末黄 mustard | `#e8b04b` | 高光、数字、贴纸 |

## 印刷质感

- 半调网点（halftone）：大色块用固定点阵纹理，不用渐变。
- 套色错位：关键色块与标题后面偏移 2–3px 的朱红/蓝色影子。
- 纸纹与轻微噪点：预生成一张固定纹理，逐帧叠加，保证确定性。
- 胶带、撕纸边、套准十字、印章式标签：用于章节切换与重点标注。

## 字体

- 中文标题：`Microsoft YaHei` / `Noto Sans SC` 粗体。
- 数字与英文：`Consolas` / `Segoe UI`，使用大字号做记分牌式信息。
- 不使用像素字体；小字不小于 18px（逻辑坐标）。

## 运动

- 平滑缓动（ease-out / ease-in-out），镜头可以推、拉、横移。
- 转场用纸张滑入、色块擦除、印章落下，不用淡入淡出。
- 轨迹、矢量、流线用 2px 墨线 + 朱红箭头；关键帧允许“定格 + 标注”。

## 三种旋转的颜色语义

- 上旋：朱红。
- 下旋：蓝。
- 侧旋：球台绿。
- 中性/未旋转：墨色。
- 强调/数据：芥末黄。

字幕仍为底部单行，但改为纸色字幕条 + 墨色字，左侧加一枚旋转类型色块。
