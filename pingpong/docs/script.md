## 物理口径

这版脚本经过一轮事实核查，重点守住以下边界：

- **弧线的主骨架是初速度 + 重力**；旋转只负责改写，不是“造出弧线”。
- **马格努斯力方向**由 `ω × v` 决定：上旋向下、下旋向上、侧旋向左右；压力差推向低压侧，不用“往侧面推”统称。
- **转速数据**只限“顶尖选手的强上旋”：可超 100 转/秒；发球通常约 40–60 转/秒，不是每一板都一百多。
- **上旋落台**是否前冲，取决于球底相对台面的滑动方向：`ωR > v_x` 时台面摩擦向前；`v_x > ωR` 时摩擦向后、球被拖慢。
- **下旋回跳**需要强下旋、足够摩擦、水平速度降到零；普通下旋多数只是减速或冒高。
- **纯侧旋**落台不会突然大侧拐；明显的“突然横拐”通常来自轴倾斜或复合旋转。
- **声音不是转速计**：不用击球声判断旋转强弱。
- **回球旋转**由来球、拍面角度、触球点、挥拍和胶皮共同决定；不是“怎么转就怎么回来”。

## 叙事原则

- 先现象、后机制：拐弯 → 轴 → 摩擦 → 空气 → 台面 → 读拍 → 收束。
- 每条屏字对应一个可见动作，不写纯抽象概念。
- 数字只保留 100+ 转/秒、40–60 转/秒、ωR/vx、-28°/+28° 这几组。
- 结尾落在可立即执行的动作：“下一次，先看拍，再看球。”
