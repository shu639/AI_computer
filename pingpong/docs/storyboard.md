# 分镜表（120 秒 / 30fps / 1920×1080）

## 全局视觉规则

- 逻辑画布 960×540；Canvas 以 2× 渲染，输出 1920×1080。
- 不用像素网格、不做 16 色量化；保留文字抗锯齿。
- RISO 孔版运动杂志：纸色背景、五色套印、半调网点、套色错位、胶带/撕纸/套准十字。
- 字体：Microsoft YaHei（中文标题/正文）、Bahnschrift（数字/英文标签）。
- 字幕条：底部 72px；30px 单行；每条不超过 19 字。
- 章节：顶部报头 + 进度线；每章一个主色。
- 转场：片头纸张上滑；章末色块擦除；片尾回到标题卡。
- 全片球向右飞；上旋顺时针、下旋逆时针；侧旋用俯视图，避免左右旋画反。

## 音效设计

- 全部由 Node 程序化合成，无采样、无旋律 BGM。
- 触拍：8ms 带通瞬态 + 330→145Hz 木质主体 + 95→58Hz 低频冲击 + 短高频 click；听感是短促的“啪”，不是长噪声尾巴。
- 落台：700–3200Hz 带通瞬态 + 640→300Hz 台面主体 + 短 click；比触拍更硬、更高。
- 胶皮：950→1470Hz 短滑音 + 少量带通噪声，只保留 85ms。
- 气流：低通（<520Hz）噪声 + 150→95Hz 低音滑音，不用宽带 whoosh。
- 纸张/转场：250–1600Hz 带通噪声 + 210Hz 三角波。
- 盖章：低频 kick + 低频带通 + 145Hz 方波。
- 读拍：1350/2250Hz 短 click。
- 比赛脉冲：100–112 BPM 的低音量 kick + rim，只做气氛，不抢屏字；开场、落台、读拍段启用。
- **不用声音强弱或音高暗示转速**；声音只做动作反馈。
- 母版经 `loudnorm I=-16 TP=-2` + 0.9 音量收尾，AAC 192k。

## 物理护栏（画面必须遵守）

- 弧线先画无旋虚线参照，再画旋转轨迹；重力箭头常驻。
- 压力标签：上侧慢/高压，下侧快/低压；力箭头指向低压侧。
- 上旋落台：球底相对球心向后转；是否前冲由 ωR 与 vx 双条决定，两种结果都演示。
- 下旋落台：球底向前滑；普通下旋减速/冒高，强下旋才画回跳虚线。
- 纯侧旋落台只画轻侧跳；“突然横拐”标注为轴倾斜/复合旋转。
- 读拍先拍面、触球点，再球标；球标只判转速，不判方向。
